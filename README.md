# 🎓 UniSchedule iOS — Расписание РГАТУ им. П. А. Соловьёва

> **Современное, быстрое и 100% нативное iOS-приложение для iPhone**, созданное специально для студентов и преподавателей **Рыбинского государственного авиационного технического университета имени П. А. Соловьёва (РГАТУ)**.

Приложение полностью переработано с Android-версии (`Lowstil/xRSATUx-Schedule`) на чистый стек Apple (**Swift 5.9+, SwiftUI, WidgetKit, UserNotifications**) с соблюдением принципов Apple Human Interface Guidelines (HIG).

---

## 📱 Почему нативный стек (Swift + SwiftUI + Xcode)?

Для разработки **исключительно под iPhone** нативный стек Apple является эталоном:
* ⚡ **Максимальная производительность:** мгновенный запуск, плавная анимация 120 Гц ProMotion, минимальный вес приложения и бережное отношение к аккумулятору iPhone.
* 🎨 **Нативный дизайн Apple:** материалы Liquid Glass, SF Symbols 5, адаптивная светлая и тёмная темы, плавные модальные экраны (Sheets) и тактильный отклик (`UIImpactFeedbackGenerator`).
* 🧩 **WidgetKit:** нативные виджеты на экран «Домой» и экран блокировки (Lock Screen).
* 🔔 **Умные локальные уведомления:** интеграция с `UNUserNotificationCenter` без необходимости держать приложение запущенным.
* 📦 **Полная готовность к App Store и TestFlight.**

## 🚀 Основные возможности

### 1. 📅 Расписание для студентов и преподавателей
- **142 группы и 164 преподавателя:** мгновенный поиск с автодополнением и фильтрацией.
- **Двухнедельный цикл семестра:** автоматический расчёт номера недели (1..18) и чётности (чётная / нечётная).
- **Навигация по неделям и дням:** удобный переключатель недель стрелками и быстрый возврат к текущей неделе в 1 тап.
- **Умные бейджи на днях:** вкладки отображают число месяца, название месяца (например, *«Октябрь – Ноябрь»*) и цветные плашки:
  - 🔵 **«Сегодня»**
  - 🟠 **«Завтра»**
  - 🟣 **«Наступит через X дн.»**

### 2. ⏱ Живой таймер пары и статус в реальном времени
- **«Идёт сейчас»:** карточка текущей пары выделяется акцентной обводкой, пульсирующим зелёным индикатором и точным счётчиком времени (*«Идёт сейчас · осталось 24 мин»*).
- **3 этапа пары:** умный прогресс-бар отслеживает этапы (1-я половина 45 мин ➔ перерыв в паре 5 мин ➔ 2-я половина 45 мин).
- **«Перемена»:** во время перерыва карточка информирует: *«Следующая · перемена (до пары 10 мин)»*.
- **«Ближайшее занятие»:** в выходные и праздники выводится карточка со следующей запланированной парой.

### 3. ⭐ «Избранное» и быстрое переключение в 1 тап
- Добавление групп и преподавателей в закладки с помощью звёздочки (⭐).
- Горизонтальная панель быстрого доступа на главном экране: мгновенное переключение между своей группой и расписанием друзей/преподавателей без перехода в поиск.

### 4. 📝 Домашние задания и личные заметки
- При нажатии на любую пару открывается диалог для записи задания (*«Сдать лабораторную №2», «Принести конспект»*).
- На карточке пары отображается бейдж с текстом задачи.
- Возможность отметить задание как выполненное (перечёркивается с зелёной галочкой) или удалить его.

### 5. 🚫 Точечный пропуск («Не пойду на пару») и 🎓 «Перезачёт»
- **«Не пойду на пару»:** через контекстное меню (долгое нажатие) пару можно отметить пропущенной — она перечёркивается и не создаёт лишних уведомлений.
- **«Перезачёт»:** исключение целых дисциплин из активного расписания для студентов с перезачтёнными предметами.

### 6. 🔔 Интерактивный справочник звонков
- Красивая модальная таблица звонков пар и перемен с разделением на:
  - **Будни (ПН–ПТ):** включая большую перемену 50 минут (11:50 – 12:40).
  - **Суббота (СБ):** специальное расписание выходного дня.
- Подсветка текущей пары прямо внутри справочника.

### 7. 📲 Виджет для экрана «Домой» (WidgetKit)
- Виджеты малого (`.systemSmall`) и среднего (`.systemMedium`) размеров:
  - Номер текущей/следующей пары, время, предмет, аудитория и преподаватель прямо на рабочем столе iPhone.

### 8. ⚡ Оффлайн-работа и автообновление
- **Мгновенный старт:** в проект встроены предсобранные актуальные данные (`SampleSchedule.json`), приложение работает сразу после установки даже без доступа в интернет.
- **Сетевое обновление:** асинхронный клиент загружает актуальные таблицы с официального сайта `rsatu.ru` с поддержкой динамического поиска ссылок и защитой от нестандартных SSL-цепочек.

## 🛠 Запуск и разработка

### Вариант 1: Запуск на Mac через Xcode
1. Склонируйте репозиторий:
   ```bash
   git clone <URL_ВАШЕГО_НОВОГО_РЕПОЗИТОРИЯ>
   cd UniSchedule-iOS
   ```
2. Откройте `UniSchedule.xcodeproj` двойным кликом в **Xcode 15 или 16**.
3. Выберите симулятор (например, **iPhone 15 / 16**) или подключите физический iPhone через кабель.
4. Нажмите **Cmd + R** для запуска!

### Вариант 2: Сборка через GitHub Actions (если вы работаете на Windows)
В репозиторий уже добавлен рабочий пайплайн `.github/workflows/ios-build.yml`:
1. Запушьте код на GitHub.
2. Вкладка **Actions** в репозитории на GitHub автоматически запустит macOS-раннер, соберёт приложение и прогонит все тесты.
