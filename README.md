# 🎓 xRSATUx Schedule (UniSchedule iOS) — Расписание РГАТУ им. П. А. Соловьёва

> **Современное, быстрое и 100% нативное iOS-приложение для iPhone (iOS 17+)**, созданное специально для студентов и преподавателей **Рыбинского государственного авиационного технического университета имени П. А. Соловьёва (РГАТУ)**.

Приложение построено на чистом стеке Apple (**Swift 5.9+, SwiftUI, UserNotifications, ImageRenderer, WidgetKit**) в эстетике **Liquid Glass (версия 3.0)** с паритетом функций Android-версии (`Lowstil/xRSATUx-Schedule`).

---

## 📱 Почему нативный стек (Swift + SwiftUI + Xcode)?

Для разработки **исключительно под iPhone** нативный стек Apple является эталоном:
* ⚡ **Максимальная производительность:** мгновенный запуск, плавные свайпы 120 Гц ProMotion, минимальный вес приложения и бережное отношение к аккумулятору iPhone.
* 🫧 **Liquid Glass UI (iOS 17+):** анимированный атмосферный градиентный фон (`AmbientBackdropView`), полупрозрачные карточки и капсулы со спекулярными бликами, левая цветная полоса типа занятия и адаптивная светлая/тёмная тема.
* ♿ **Доступность и энергосбережение:** переключатель **«Уменьшить прозрачность»**, а также автоматический учёт системного `Reduce Transparency` и режима энергосбережения (`Low Power Mode`).
* 🔔 **Умные локальные уведомления:** интеграция с `UNUserNotificationCenter` — напоминания до пары, утренний дайджест в 07:30 и **живые уведомления этапов пары 45-5-45**.
* 📦 **Готовность к TestFlight и CI/CD:** автоматическая сборка и модульные тесты через GitHub Actions.

## 🚀 Основные возможности (включая обновление 3.0 Liquid Glass)

### 1. 🫧 Liquid Glass интерфейс и навигация свайпами
- **Атмосферный фон (`AmbientBackdropView`):** плавно переливающиеся градиентные сферы и тонкая текстура; при активной текущей паре фон приобретает тёплое изумрудно-янтарное свечение.
- **Горизонтальные свайпы по 6 дням недели (ПН–СБ):** плавный `TabView` свайп-пейджер, синхронизированный с капсулами дней в `WeekDayPickerView`.
- **Детектор «окон» между парами (`LessonWindowCardView`):** при перерыве $\ge 2$ пар (учитывая будни и субботу) автоматически отображается карточка `☕ Окно · X ч Y мин` с точным интервалом времени, игнорируя отменённые, пропущенные и перезачтённые занятия.
- **Умный автооткрыватель воскресенья (`DateUtils.initialScheduleDate`):** при запуске в воскресенье расписание автоматически открывается на понедельник следующей недели; переключение недель стрелками всегда открывает понедельник, а тап по заголовку недели возвращает к текущему дню.
- **Быстрый поиск и избранное:** 142 группы и 164 преподавателя, звёздочка избранного и **удаление чипа из избранного долгим нажатием** с подтверждением.

### 2. ⏱ Живой таймер пары, 45-5-45 и ближайшее занятие
- **«LIVE» и «ДАЛЕЕ»:** карточка текущей пары подсвечивается изумрудным стеклом с пульсирующим бейджем `LIVE` и прогресс-баром этапов **45-5-45** (1-я половина 45 мин ➔ перерыв 5 мин ➔ 2-я половина 45 мин); следующая пара на сегодня выделяется небесно-голубым бейджем `ДАЛЕЕ`.
- **Живые уведомления пары (`NotificationManager`):** уведомления на старт пары, 5-минутный перерыв и 2-ю половину пары (управляются тумблером в настройках).
- **Точный поиск ближайшего занятия (`findNextLesson`):** учитывает чётность каждой проверяемой даты, праздники, отмены, перезачёты и поставленные «Н-ки».

### 3. 📊 Посещаемость 3.0, бюджет пропусков и «Перезачёт»
- **Отметка пары по долгому нажатию (или контекстному меню):**
  - **🟢 «Посетил / Пойду»** — отмечает пару в зачёт (`✓ Посещено` или `✓ Пойду` для будущих дат).
  - **🔴 «Поставить Н-ку (Пропуск)»** — зачёркивает карточку, ставит `🔴 Н-ка` и отключает напоминания.
  - **⚪ «Сбросить отметку»** — очищает статус пары.
- **Экран «Моя посещаемость»:**
  - **Кольцевые индикаторы прогресса (`CircularProgressRingView`)** для общей посещаемости и каждого предмета.
  - **Настраиваемый порог допустимых пропусков (`20% / 25% / 30%`)** с живым пересчётом запаса: *«Можно пропустить ещё N пар»*, *«Последний запас: 1 пара»*, *«Запас исчерпан»*, *«Лимит превышен!»* и цветовой индикацией (`BudgetHealth`).
  - **Ручная корректировка (`+` / `−`)** и предупреждения при $\ge 3$ «Н-ках».
- **🎓 «Перезачёт»:** скрытие зачтённых дисциплин из активного расписания, таймеров и уведомлений.

### 4. 🔍 Поиск преподавателя и свободных аудиторий (офлайн)
- **Вкладка «Где преподаватель?»:** мгновенный поиск по преподавателям, отображение текущей или следующей пары прямо сейчас и всего расписания на день.
- **Вкладка «Свободные аудитории»:** фильтр по корпусам (**Все**, **Главный (Г)**, **1 / 2 / 3 корпус**) и выбор номера пары (1–6) с автовыбором текущей/следующей пары.

### 5. 🔄 «Что изменилось» (`ScheduleDiff`) и 📤 Экспорт (Текст + PNG)
- **Автоматический дифф при обновлении:** при загрузке свежего расписания с `rsatu.ru` приложение сравнивает старую и новую версии выбранной группы/преподавателя, фиксирует добавленные/удалённые пары, смену аудитории или преподавателя и показывает экран **«Что изменилось»** (также доступен вручную из меню и настроек).
- **Экспорт расписания (`ScheduleExporter`):** отправка через системный Share Sheet на **сегодня** или **текущую неделю** в виде аккуратного текста или **тёмной карточки-картинки Liquid Glass (PNG 1080px)** через `ImageRenderer`.

### 6. 🔔 Справочник звонков, 📝 заметки, 📲 виджеты и оффлайн-режим
- **Таблица звонков:** будни (большая перемена 50 мин) и суббота, с подсветкой активной пары.
- **Домашние задания и заметки:** запись задачи к любой паре с отметкой выполнения.
- **Встроенная база (`SampleSchedule.json` / `schedule.xlsx`):** работает сразу после установки, автоматически обновляется с `rsatu.ru` (парсинг `.xlsx` через встроенный `XLSXReader`).

## 🛠 Запуск и разработка

### Вариант 1: Запуск на Mac через Xcode
1. Склонируйте репозиторий:
   ```bash
   git clone <URL_ВАШЕГО_НОВОГО_РЕПОЗИТОРИЯ>
   cd UniSchedule-iOS
   ```
2. Откройте `UniSchedule.xcodeproj` двойным кликом в **Xcode 15 или 16**.
3. Выберите симулятор (например, **iPhone 15 / 16**) или подключите физический iPhone через кабель.
4. Нажмите **Cmd + R** для запуска!

### Вариант 2: Сборка через GitHub Actions (если вы работаете на Windows)
В репозиторий уже добавлен рабочий пайплайн `.github/workflows/ios-build.yml`:
1. Запушьте код на GitHub.
2. Вкладка **Actions** в репозитории на GitHub автоматически запустит macOS-раннер, соберёт приложение и прогонит все тесты.
