# 🎓 xRSATUx Schedule (UniSchedule iOS) — Расписание РГАТУ им. П. А. Соловьёва

> **Современное, быстрое и 100% нативное iOS-приложение для iPhone (iOS 17+)**, созданное специально для студентов и преподавателей **Рыбинского государственного авиационного технического университета имени П. А. Соловьёва (РГАТУ)**.

Приложение построено на чистом стеке Apple (**Swift 5.9+, SwiftUI, CryptoKit, PhotosUI, UserNotifications, ImageRenderer, WidgetKit**) в эстетике **Liquid Glass (версия 3.3.1)** с паритетом функций Android-версии (`Lowstil/xRSATUx-Schedule`) и новой авиационной иконкой РГАТУ в стиле Liquid Glass.

---

## 📱 Почему нативный стек (Swift + SwiftUI + Xcode)?

Для разработки **исключительно под iPhone** нативный стек Apple является эталоном:
* ⚡ **Максимальная производительность:** мгновенный запуск, ленивый 216-страничный свайп-пейджер без перегрузки памяти, плавные свайпы 120 Гц ProMotion и бережное отношение к аккумулятору iPhone.
* 🫧 **Liquid Glass UI (iOS 17+):** анимированный атмосферный градиентный фон (`AmbientBackdropView`), плавающий нижний док-капсула (`FloatingGlassDockView`), полупрозрачные карточки со спекулярными бликами и адаптивная светлая/тёмная тема.
* ♿ **Доступность и энергосбережение:** переключатель **«Уменьшить прозрачность»** с мгновенным откликом фона, а также автоматический учёт системного `Reduce Transparency` и режима `Low Power Mode`.
* 🔔 **Умные локальные уведомления:** интеграция с `UNUserNotificationCenter` — напоминания до пары, утренний дайджест в 07:30 и **живые уведомления этапов пары 45-5-45** (активны строго во время идущей пары).
* 📦 **Готовность к TestFlight и CI/CD:** автоматическая сборка и модульные тесты `XCTest` через GitHub Actions.

## 🚀 Основные возможности (v3.0 – v3.3.1 Liquid Glass)

### 1. 🗓 Два семестра («Осень / Весна»), 216-страничный пейджер и авто-переключение
- **Единый свайп-пейджер на 36 недель (216 страниц):** бесшовное горизонтальное перелистывание по дням осеннего (`0..107`) и весеннего (`108..215`) семестров с ленивой загрузкой, кэшированием по ключу `sem:week` и предзагрузкой соседних недель.
- **Плавающий индикатор семестра (`SemesterToastPill`):** при перелистывании через границу семестров сверху появляется стеклянная капсула (`🍂 Осенний семестр` / `🌸 Весенний семестр`), а для ещё не опубликованного семестра отображается информационная карточка с кнопкой **«Проверить сейчас»**.
- **Календарные окна и SHA-256 автоопределение (`SemesterManager` + `NetworkService`):**
  - Весенний семестр: **30 января – 24 августа**, осенний: **25 августа – 29 января** (даты старта нормализуются к понедельнику).
  - При обновлении `.xlsx` с `rsatu.ru` вычисляется **SHA-256** файла: пока вуз отдаёт прежний файл, новый семестр не затирается, а при публикации свежего файла приложение автоматически сохраняет его в актуальный семестр и переключается на него.
- **Полная семестровая изоляция:** расписания пар, посещаемость, дифф обновлений и поиск свободных аудиторий/преподавателей изолированы по семестрам.

### 2. 🫧 Плавающий Liquid Glass Dock и навигация
- **Нижняя панель-капсула (`FloatingGlassDockView`):** быстрый доступ к 4 разделам — **Пары** (возврат к сегодняшнему дню), **Н-ки** (посещаемость), **Аудитории** (поиск аудиторий и преподавателей) и **Ещё** (с живым счётчиком невыполненных заданий `99+`).
- **Меню «Ещё»:** объединяет создание личного события, сравнение двух групп, хаб домашних заданий, таблицу звонков, историю изменений («Что изменилось»), обновление расписания и настройки.
- **Детектор «окон» (`LessonWindowCardView`):** при перерыве $\ge 2$ пар (с учётом будней и субботы) автоматически отображается карточка `☕ Окно · X ч Y мин`, игнорируя отменённые, пропущенные и перезачтённые занятия.
- **Умный автооткрыватель воскресенья и быстрые действия избранного:** при запуске в воскресенье открывается понедельник следующей недели; долгое нажатие по чипу избранной группы открывает меню действий (**«⚖️ Сравнить с текущей»** и **«🗑 Удалить из избранного»**).

### 3. 📝 Хаб домашних заданий, фото-заметки и личные события
- **«Задания и заметки» (`HomeworkHubSheet`):** единый список всех заметок к парам с фильтром **Активные / Все / Выполнено**, прикреплением фотографий (`PhotosPicker` + локальное хранение в `Documents/note_photos/`), полноэкранным просмотром фото, отметкой выполнения и **переходом к нужной дате расписания по тапу на карточку**.
- **Личные события (`CustomEvent` / `CustomEventSheet`):** добавление собственных мероприятий (консультации, кружки, встречи) на **конкретную дату** или **еженедельно** (ПН–СБ, каждая / нечётная / чётная неделя, 1–7 пара) для выбранной группы или преподавателя. Личные события помечаются фиолетовым бейджем «Личное» и автоматически попадают в расписание, окна, поиск ближайшей пары, виджеты, утренний дайджест и напоминания.

### 4. ⚖️ Сравнение двух групп («Общие окна») и интерактивные корпуса
- **Сравнение расписаний (`CompareScheduleSheet`):** послотовый анализ 1–7 пар для двух студенческих групп с выбором недели, дня и быстрыми чипами избранного:
  - `🟢 Общее окно` · `🔵 Заняты оба` · `🟡 Занята одна группа` + сводная статистика.
- **Интерактивные корпуса и преподаватели (`BuildingInfoSheet` + `RoomFormatter`):**
  - Тап по имени преподавателя в карточке пары сразу открывает Finder на его расписании.
  - Тап по аудитории открывает карточку корпуса (Главный, 1, 2, 3, Точка кипения, Большой спортзал, Онлайн, Место практики) с адресом в Рыбинске, временем перехода пешком и кнопкой **«Свободные аудитории»** с переходом в нужный корпус.

### 5. 🔍 Поиск преподавателя и свободных аудиторий v3.3.1 (`RoomTeacherFinderSheet`)
- **Вкладка «Где преподаватель?»:** поиск с привязкой к выбранному семестру, автоматическое сопоставление при открытии из карточки пары, текущая/следующая пара прямо сейчас и расписание на день.
- **Вкладка «Свободные аудитории»:**
  - Фильтры **«Неделя и день:»** (переключатель **Нечётная / Чётная** + выбор дня **ПН–СБ**),
  - Фильтр по корпусам (**Все**, **Главный (Г)**, **1 / 2 / 3 корпус**),
  - Расширенный выбор номера пары (**1–7 пара**),
  - Динамическая строка сводки и учёт воскресенья.

### 6. ⏱ Живой таймер 45-5-45, посещаемость, виджет «Завтра» и настройки
- **«LIVE» и «ДАЛЕЕ» + живые уведомления:** карточка активной пары с прогресс-баром **45-5-45** (1-я половина 45 мин ➔ перерыв 5 мин ➔ 2-я половина 45 мин); живые уведомления автоматически отменяются в перемены, окна и после окончания занятий.
- **Посещаемость и «Перезачёт»:** долгое нажатие на пару для отметки `✓ Посещено / Пойду` или `🔴 Н-ка`, кольцевые индикаторы прогресса, настраиваемый порог пропусков (**20% / 25% / 30%**), поиск по предметам в диалоге «Перезачёт».
- **Виджет рабочего стола (`UniScheduleWidget`):** после завершения всех активных пар сегодняшнего дня автоматически переключается на **предпросмотр завтрашнего дня** (или понедельника в субботу вечером: `Завтра · ПН` / `ПН, 18.11`) с корректным расписанием звонков.
- **Настройки и «О приложении»:** переключатель семестра **«Осень / Весна»**, живое обновление прозрачности фона, Liquid Glass диалог подтверждения **«Очистить данные»** и карточка **«О приложении»** (`v3.3.1`, дата обновления расписания и кнопка релизов на GitHub).
- **«Что изменилось» и экспорт:** автоматический дифф при обновлении расписания и экспорт дня/недели в текст или тёмную PNG-карточку Liquid Glass.

## 🛠 Запуск и разработка

### Вариант 1: Запуск на Mac через Xcode
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Lowstil/xRSATUx-Schedule-iOS.git
   cd UniSchedule-iOS
   ```
2. Откройте `UniSchedule.xcodeproj` двойным кликом в **Xcode 15 или 16**.
3. Выберите симулятор (например, **iPhone 15 / 16**) или подключите физический iPhone через кабель.
4. Нажмите **Cmd + R** для запуска!

### Вариант 2: Сборка через GitHub Actions
В репозиторий добавлен рабочий пайплайн `.github/workflows/ios-build.yml`:
1. Запушьте код на GitHub.
2. Вкладка **Actions** в репозитории автоматически запустит macOS-раннер, соберёт приложение и прогонит все тесты `UniScheduleTests`.
